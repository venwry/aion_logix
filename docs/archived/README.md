# Historical archive of documentation

These reports describe past storytelling work, proposals, migrations, assessments or superseded documentation. **They are not valid current rules, instructions or queue status.** Their dates and pending/approved labels belong to their original snapshots. Archiving neither approves nor rejects any story record.

Use the [current documentation index](../README.md), [reference rules](../data_model/REFERENCE_RULES.md) and live [proposal queue](../../data_storytelling/change.json) instead. The [relocation index](relocation-index.json) records original paths, source commit and checksums. Archived Markdown has a historical banner and repaired relative links; original bytes remain recoverable at the recorded commit. JSON evidence retains its original snapshot meaning.
